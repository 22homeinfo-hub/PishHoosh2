# ربات دفتر املاک دیار

ربات هوشمند دریافت اطلاعات فایل ملکی و تخمین قیمت، برای تلگرام و لندینگ‌پیج.

## ساختار پروژه

```
src/
  index.js        نقطه شروع - هم بات تلگرام هم سرور وب رو راه میندازه
  telegram.js      اتصال به تلگرام
  webApi.js        API برای لندینگ‌پیج
  conversation.js  منطق مشترک مکالمه (بین تلگرام و وب مشترکه)
  ai.js            اتصال به Gemini، مدیریت مکالمه و تخمین قیمت
  sheets.js        اتصال به Google Sheets (خواندن پروژه‌ها، ثبت لیدها)
  sessions.js      نگهداری وضعیت مکالمه هر کاربر در حافظه
```

## مراحل راه‌اندازی

### ۱. Google Service Account (برای دسترسی به Google Sheets)

این بخش کمی فنی‌تره ولی فقط یک‌بار لازمه:

1. برید به: https://console.cloud.google.com/
2. یک پروژه جدید بسازید (یا پروژه‌ای که برای Gemini ساختید رو انتخاب کنید)
3. از منو، برید به **APIs & Services → Library**
4. سرچ کنید "Google Sheets API" و **Enable** کنید
5. برید به **APIs & Services → Credentials**
6. **Create Credentials → Service Account**
7. یک اسم بدید (مثلا `diyar-bot-sheets`) و Create کنید
8. بعد از ساخته شدن، روی سرویس اکانت کلیک کنید → تب **Keys** → **Add Key → Create New Key → JSON**
9. یک فایل JSON دانلود میشه. داخلش دو تا مقدار لازم داریم:
   - `client_email` → این میره توی `GOOGLE_SERVICE_ACCOUNT_EMAIL`
   - `private_key` → این میره توی `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY`

10. حالا برید توی Google Sheet خودتون (همون فایلی که پروژه‌ها رو توش پر کردید) و روی **Share** بزنید، همون `client_email` رو با دسترسی **Editor** اضافه کنید. این مرحله حیاتیه — بدون این، ربات نمی‌تونه شیت رو بخونه یا بنویسه.

### ۲. پر کردن فایل `.env`

فایل `.env.example` رو کپی کنید به اسم `.env` و مقادیر واقعی رو جایگزین کنید:

```bash
cp .env.example .env
```

سپس `.env` رو باز کنید و پر کنید:
- `TELEGRAM_BOT_TOKEN` → از BotFather
- `GEMINI_API_KEY` → از aistudio.google.com/apikey
- `GOOGLE_SHEET_ID` → از لینک شیت (بخش بین `/d/` و `/edit`)
- `GOOGLE_SERVICE_ACCOUNT_EMAIL` و `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` → از فایل JSON مرحله قبل

⚠️ نکته مهم برای `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY`: این مقدار چندخطیه و باید داخل کوتیشن باشه، دقیقا همونطور که توی JSON اومده (با `\n` داخلش).

### ۳. نصب و اجرای محلی (تست قبل از دیپلوی)

```bash
npm install
npm start
```

اگه همه‌چیز درست باشه، این پیام‌ها رو می‌بینید:
```
✅ بات تلگرام فعال شد
✅ سرور وب روی پورت 3000 فعال شد
```

حالا می‌تونید توی تلگرام به بات پیام `/start` بدید و تست کنید.

### ۴. دیپلوی روی Railway (رایگان برای شروع)

1. یک اکانت GitHub بسازید (اگه ندارید) و این پروژه رو توش آپلود کنید (یا از من بخواید کمک کنم)
2. برید به https://railway.app و با GitHub وارد بشید
3. **New Project → Deploy from GitHub repo** → این ریپو رو انتخاب کنید
4. توی تنظیمات پروژه، برید به تب **Variables** و همه مقادیر فایل `.env` رو اونجا وارد کنید (Railway از `.env` فایل استفاده نمی‌کنه، باید دستی وارد کنید)
5. Railway خودش دیپلوی می‌کنه و یک لینک بهتون می‌ده

## اتصال به لندینگ‌پیج

بعد از دیپلوی، سرور یک API در این آدرس‌ها می‌ده:
- `GET /api/welcome` → پیام خوش‌آمدگویی و لیست پروژه‌ها
- `POST /api/message` → ارسال پیام کاربر، بدنه: `{ "sessionId": "...", "text": "..." }`

کد لندینگ‌پیج (ویجت چت HTML/JS) در مرحله بعد آماده می‌کنم و به همین API وصلش می‌کنم.

## نکات مهم

- **پروژه‌ها**: هر تغییری که توی شیت Projects بدید (اضافه/ویرایش/غیرفعال کردن)، حداکثر تا ۲ دقیقه بعد خودش توی ربات اعمال میشه (به خاطر کش داخلی).
- **هزینه‌ها**: Gemini API سهمیه رایگان روزانه داره؛ اگه ترافیک خیلی بالا بره ممکنه نیاز به پلن پولی بشه، ولی برای شروع کافیه.
- **امنیت**: هیچ‌وقت فایل `.env` رو جایی پابلیک (مثل GitHub عمومی) آپلود نکنید. این فایل باید توی `.gitignore` باشه.
